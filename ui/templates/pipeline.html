The Seven-Step Pipeline

Every X-ray you submit passes through each of these stages — from raw pixels to an explained, uncertainty-aware KL grade.

1
Image Preprocessing
Technique: CLAHE + Z-score Normalisation
The raw X-ray is resized to 224 × 224 pixels and converted to grayscale. CLAHE (Contrast-Limited Adaptive Histogram Equalisation) is then applied with a clip limit of 2.0 and 8×8 tiles — this locally boosts contrast in bone and cartilage regions while suppressing scanner noise and over-bright scanner backgrounds.

Finally the pixel values are normalised using the training-set mean (0.579) and standard deviation (0.145) computed by Welford's online algorithm over 5,778 training images. The single grayscale channel is repeated three times so the image can be fed to an ImageNet-pretrained ResNet-50 backbone.

2
Dual-Stream Feature Extraction
Technique: Dual-Stream ResNet-50 with Center Zoom
A single ResNet-50 backbone is passed the same image twice in parallel:
🌐 Global Stream
🔍 Local Stream
⊕ Feature Fusion
The global stream sees the full 224×224 image — capturing overall bone geometry, bilateral symmetry, and large deformities. The local stream receives a 72%-centred crop that zooms into the joint-space region, capturing fine-grained cartilage thinning and osteophyte detail. The 2×2048-dimensional feature vectors are then concatenated and projected through a dropout (p=0.3) and a linear layer to form the shared representation.
3
Ordinal Severity Learning
Technique: Cascade Binary Head + CORN Ordinal Loss
Instead of treating KL-0 through KL-4 as five independent categories, the model uses a cascade ordinal head: one binary gate (OA vs. No-OA) followed by three cumulative binary classifiers (KL≥2, KL≥3, KL≥4). This architecture encodes the natural ordering of disease severity — predicting KL-0 when the truth is KL-4 is penalised far more heavily than a one-step error.

Multi-task auxiliary OARSI features (joint-space narrowing medial/lateral, osteophyte medial/lateral) further guide the model to focus on the anatomically meaningful signals.

4
Training with Patient-Grouped 5-Fold Cross-Validation
Technique: Stratified Patient-Level K-Fold + Weighted Sampler
The dataset contains 4,130 unique patients, each contributing both a left and right knee image. All images from the same patient are kept in the same fold — preventing data leakage and ensuring generalisation is measured at the patient level, not the image level.

Within each training fold a WeightedRandomSampler oversamples rare KL-4 images (13× fewer than KL-0) so every mini-batch sees all five grades. Class weights in the loss function reinforce this. Five fold models are trained and their predictions are averaged at inference (ensemble of five).

5
Prediction & Calibrated Decoding
Technique: Expected-Grade Decoding + OOF Cutpoint Calibration
The five-fold ensemble produces a probability vector [P(KL-0), …, P(KL-4)] by averaging logits across folds. A simple argmax would not make best use of the ordinal probability structure, so an expected grade (the probability-weighted mean grade) is computed instead.

Four cut-points on this expected-grade scalar are then fit on out-of-fold (OOF) predictions by coordinate search maximising Quadratic Weighted Kappa. These OOF-tuned cut-points (0.609 / 1.267 / 2.243 / 3.050) are applied at test time, lifting the locked-test QWK from 0.861 (argmax) to 0.867.

6
Explainability — Dual-Stream Grad-CAM
Technique: Per-Stream Gradient-Weighted Class Activation Mapping
Grad-CAM computes the gradient of the target class score with respect to the final convolutional feature map, global-average-pools those gradients into per-channel importance weights, and linearly combines the maps. Because this model runs the backbone twice (global and local streams), a correct per-stream Grad-CAM is computed separately for each pass using autograd.grad — preventing gradient mixing between streams.

The local-stream CAM (computed in the zoomed coordinate frame) is up-sampled and pasted back into the matching centre box of the full image. The two maps are blended into a single combined heatmap overlaid on the original X-ray.

AFS (Anatomy Focus Score) measures the fraction of Grad-CAM energy that falls within the anatomically expected knee-joint band — 97% of test images exceed the 0.5 threshold. ESS (Explanation Stability Score) is the SSIM between heatmaps under mild image perturbations (±5% brightness, Gaussian noise) — mean 0.947 means explanations are essentially unchanged by irrelevant image variations.
7
Uncertainty Quantification
Technique: MC Dropout (N=30) + Expected Calibration Error
A reliable clinical AI must know what it does not know. At inference time, the dropout layers are kept active (training mode) while batch-norm stays in eval mode. The model is run 30 times on the same image — each pass produces a slightly different probability vector because different neurons are dropped each time.

The variance across 30 passes gives a per-sample uncertainty estimate. High entropy → the model is uncertain → the case should be flagged for expert review. KL-1 and KL-2 (the boundary grades) predictably show the highest entropy, matching clinical expectation.

ECE (Expected Calibration Error) of 0.021 confirms the model's confidence scores are well-calibrated: a prediction reported at 70% confidence is correct roughly 70% of the time.
